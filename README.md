## Лаба 1 — коротко

**Застосунок:** Notes API — REST API для нотаток (Python, FastAPI + PostgreSQL), з документацією Swagger на `/docs`.

**Хмара:** AWS (`eu-north-1`) — ECR, RDS PostgreSQL у приватній підмережі, ECS Fargate за Application Load Balancer; уся інфраструктура в Terraform; автоматичний деплой через GitHub Actions з OIDC (без збережених ключів).

**Бонуси:** автентифікація JWT (401 без токена), моніторинг CloudWatch (дашборд + алерти на email), Swagger.

## Лаба 2 — коротко

За умовою Лаба 2 робиться **в тому самому Terraform-проєкті і репозиторії**, що й Лаба 1, тому її код — у `Lab1/`:

- **автомасштабування** ECS 1–4 задачі за CPU 60 %, **за розкладом** удень мінімум 2, уночі 1;
- **навантажувальний тест** k6 (1 запис + 9 читань, 3 фази, одна команда `.\loadtest\run.ps1`);
- **дашборд CloudWatch** (екземпляри, CPU, запити/хв, p95, 5xx, кеш, БД, черга) і **email-алерт** CPU > 70 % (лист ALARM і лист OK);
- **кеш cache-aside** у спільному Redis (TTL 30 с);
- **черга SQS** з обробником, що масштабується від довжини черги (`202 Accepted`), і **Idempotency-Key** у Redis на 24 год.

Опис, ендпоінти, архітектура і **повна інструкція з командами** (локальний запуск, деплой, перевірка кожної вимоги обох лаб, видалення) — у [`Lab1/README.md`](Lab1/README.md).
